# Forward-test results v2

Date: 2026-08-12

Fresh agents tested the new People OS skills from realistic prompts, using only each selected skill and its progressively disclosed resources. No agent modified the suite.

## Data Academy — pass

Prompt: design a six-month Junior-to-Senior Data Engineer program with theory, practice, assessment and certification.

- Selected `academy-build-competency-curriculum-map` with the learning lifecycle.
- Produced a 24-week theory/practice progression, formative gates, capstone, independent assessment, remediation and transfer checks.
- Correctly bounded “Senior-ready” to demonstrated competencies rather than title or promotion.
- Follow-up testing led to direct role-curriculum/template routing, a level crosswalk, employment-impact R3 escalation, a canonical downstream task chain and complete certification evidence fields.

## Data onboarding — pass

Prompt: create a 90-day Senior Analytics Engineer onboarding plan with access readiness, stakeholder integration, first value, checkpoints and exit criteria.

- Selected `onboard-plan-new-hire-onboarding` with the onboarding lifecycle.
- Covered preboarding, least-privilege access, 7/30/60/90 evidence gates, role-specific first value and transition to development planning.
- Did not represent planned access or contributions as completed.
- Follow-up testing led to entitlement-level approval/test evidence, a recordable 0–3 checkpoint rubric, Senior-level overlays and consistent R2 planning/R3 access/R4 offboarding escalation.

## Structured Data hiring — pass

Prompt: design a fair Senior Data Engineer hiring process with scorecard, loop, work sample, rubric, debrief and decision gate.

- Selected `talent-design-structured-interview-loop` with the hiring lifecycle.
- Produced job-related competencies, standardized stages, anchored scoring, independent evidence, accessibility controls and evidence-first debrief rules.
- Follow-up testing led to a complete composed-workflow state and templates for scorecard, loop, candidate packet, assessment rubric, interviewer guide, calibration, evidence, debrief and fairness/validity audit.
- Live candidate-impact tasks are R3-controlled; corroborating signals are explicitly non-scoring by default to prevent double-counting.

## Result

All three scenarios passed routing, lifecycle selection, evidence discipline, test gates, safety and actionability after targeted improvements. Environment-specific execution still requires company role frameworks, policies, systems, owners and approval authority.
