# Data Department Agent Skills v3.14.0

**Đổi tên một skill.** Đây là thay đổi phá vỡ tương thích với bất kỳ chỗ nào đang gọi tên cũ.

## `shared-data-core` → `shared-task-controls`

Cái tên cũ nói vị trí của skill trong sơ đồ tổ chức, không nói nó làm gì. "Shared" và "core"
mô tả chỗ đứng; người đọc vẫn không biết mở nó ra thì gặp gì.

Nó chứa 18 việc nền chung cho mọi task dữ liệu: phân loại yêu cầu, chốt success contract,
khám phá tài sản, soi schema, profiling, kiểm quyền truy cập, xử lý dữ liệu nhạy cảm, chạy
SQL an toàn, xin phê duyệt, ghi quyết định, xác minh deliverable, bàn giao. Đó là **các cổng
kiểm soát dùng chung của một task** — và tên mới nói đúng thế, theo chính ngôn ngữ trong mô
tả tự khai của nó.

Đây là cái tên mù mờ duy nhất trong 33 skill. Bộ này đổi một lần, không đổi dần.

## Cái gì KHÔNG đổi

**Task ID giữ nguyên tiền tố `core-`.** `core-build-task-context-package`,
`core-inspect-dataset-schema` và 16 task còn lại giữ nguyên ID. Đổi chúng sẽ phá mọi tham
chiếu chéo trong 868 contract, các eval case, workflow, retrieval index và knowledge graph —
đắt hơn nhiều so với giá trị của sự đồng bộ tên gọi.

**Lệnh `/dd-core` giữ nguyên.** Nó là chữ viết tắt, giống `/dd-ae` cho analytics-engineering.

Hệ quả: một skill có ba cách gọi — tên `shared-task-controls`, lệnh `/dd-core`, tiền tố task
`core-`. Đó là giá phải trả để tên nói đúng chức năng mà không phá tham chiếu.

## Di trú

Sửa mọi chỗ đang gọi tên cũ:

```bash
grep -rn "shared-data-core" .          # tìm
# đổi thành shared-task-controls
```

Chỗ thường gặp: workflow đã lưu, script trỏ đường dẫn cứng
`skills/shared-data-core/scripts/...`, và prompt có ghi tên skill.

Bản thân bộ này có một script như vậy — `company-data-context/scripts/build_context_package.py`
trỏ sang script dùng chung bằng đường dẫn cứng. Nó sẽ hỏng lúc chạy chứ không phải lúc
validate, nên nếu bạn có script tương tự, hãy tìm bằng `grep` chứ đừng trông vào validator.

Cập nhật plugin:

```bash
claude plugin marketplace update data-department
claude plugin update data-department-agent-skills@data-department
```
