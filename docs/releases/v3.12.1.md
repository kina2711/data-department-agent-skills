# Data Department Agent Skills v3.12.1

Sửa một lỗi khiến plugin **không nạp được**. Nếu bạn đang dùng v3.11.0 hoặc v3.12.0, hãy cập nhật.

## Plugin không nạp được

Manifest khai `"hooks": "./hooks/hooks.json"`. Claude Code tự nạp đường dẫn chuẩn ấy, nên
khai thêm là nạp cùng một tệp hai lần, và Claude Code từ chối toàn bộ plugin:

```
Status: ✘ failed to load
Error: Hook load failed: Duplicate hooks file detected: ./hooks/hooks.json
```

Trường `hooks` trong manifest dành cho các tệp hook **bổ sung**, không phải cho tệp vốn đã
được tìm thấy. Nó đã được gỡ.

Điều đáng nói: `claude plugin validate --strict` vẫn báo pass với manifest hỏng. Lỗi chỉ
xuất hiện lúc nạp thật. Một plugin không nạp được thì trông hệt như một plugin chưa từng
được cài — không có lệnh nào, không có skill nào, và không có gì báo cho bạn biết.

## Ngoài ra

Không có thay đổi nội dung nào so với v3.12.0: vẫn 33 role skill, 868 atomic task contract,
52 slash command, 6 wave. Chỉ manifest được sửa.
